# Skill for Technical Writers

This folder contains everything you need to use the `write-the-docs` AI skill in your documentation repository.

## Contents

| File | Type | Description |
|---|---|---|
| [What-is-a-Skill.md](What-is-a-Skill.md) | Concept | Explains what a skill is and how it helps you write better documentation. |
| [How-to-Install-the-Skill.md](How-to-Install-the-Skill.md) | Task | Step-by-step instructions for adding the skill to your repository. |
| [How-to-Use-the-Skill.md](How-to-Use-the-Skill.md) | Task | How to activate the skill and ask the AI to write or review a page. |
| [Example-and-Results.md](Example-and-Results.md) | Reference | A real prompt and the output it produced, with an explanation of every guideline applied. |
| [write-the-docs.md](write-the-docs.md) | Skill file | The skill file itself — copy this into `.claude/skills/` in your repository. |

## Quick Start

1. Read [What is a Skill?](What-is-a-Skill.md) to understand how skills work.
2. Follow [How to Install the Skill](How-to-Install-the-Skill.md) to set up the `write-the-docs` skill.
3. Follow [How to Use the Skill](How-to-Use-the-Skill.md) to start writing documentation with AI assistance.
4. Refer to [Example and Results](Example-and-Results.md) to see what correct output looks like.
