# Example: Using the write-the-docs Skill

## Summary

This page shows a complete before-and-after example of using the `write-the-docs` skill. It illustrates the prompt a student typed, the page Claude produced, and an explanation of how each part of the output maps to the instructor's guidelines.

## The Prompt

After activating the skill with `/write-the-docs`, the student typed:

> Write a Concept page for new users of the Calculator app explaining what the app is.

---

## The Output

Claude produced the following page:

---

### What is the Calculator App?

#### Summary

The Calculator app is a simple tool that lets you perform basic arithmetic operations — addition, subtraction, multiplication, and division — directly from your browser or desktop.

#### Detailed Overview

The Calculator app is designed for everyday users who need to perform quick calculations without opening a full spreadsheet or programming tool. It provides:

- A numeric keypad for entering numbers.
- Operator buttons for the four basic arithmetic operations (+, −, ×, ÷).
- A display screen that shows your current input and the result.
- A Clear button that resets the calculation to zero.

The app does not require installation or login. You open it in a browser, use it, and close it — no data is saved between sessions.

![Screenshot of the Calculator app showing the numeric keypad and display screen](images/calculator-overview.png)

#### Example

A student needs to calculate how much they will pay in total for three textbooks priced at €12, €18, and €25. They open the Calculator app, add the three amounts one by one, and the app displays the total: €55.

---

## What Makes This Output Correct

| Guideline | How the output applies it |
|---|---|
| Information type is Concept | The page explains what the app is — no procedure steps are included. |
| Correct Concept structure | All three required sections are present: Summary, Detailed Overview, Example. |
| Summary is brief | The Summary is one sentence that tells the user what they will learn. |
| Detailed Overview uses visuals | An image placeholder is included with a descriptive alt text. |
| Example uses real values | The example uses specific prices (€12, €18, €25) instead of generic placeholders like "some number". |
| Audience-appropriate language | The language is simple and avoids jargon, suitable for new users. |
| No mixed information types | The page contains no task steps or reference tables. |
